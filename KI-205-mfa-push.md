# KI-205 — MFA push not received

## Symptoms
- MFA push never arrives
- Sign-in times out

## Workaround (User)
1. Confirm phone has internet
2. Verify device time is set automatically
3. Try alternative method (code/SMS) if allowed

## Resolution (IT)
- Re-register authenticator device
- Confirm user is correctly enrolled
- Assign to Access Team if unresolved

## Suggested classification
- Category: Access
- Priority: P2
